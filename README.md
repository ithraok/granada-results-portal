# بوابة نتائج المهارات الرقمية — مدرسة غرناطة

الرابط الأساسي: https://granada-results-demo.granada-results-demo.workers.dev/

رابط أولياء الأمور: https://ithraok.github.io/granada-results-portal/

القالب المعتمد يحافظ على التصميم الأصلي، ويعرض الفترة الأولى ببياناتها، والفترة الثانية بأصفار مؤقتة حتى بدء الرصد، وملخص الفصل بثلاث بطاقات تقديرية بانتظار اكتمال الفترتين. لم يُربط مصدر Excel للفترة الثانية بعد.

index.html يحوّل إلى خدمة Cloudflare لضمان عمل مطابقة هوية الطالب وجوال ولي الأمر والجلسة الآمنة على المصدر نفسه. portal-source.html نسخة كود الواجهة، وapp.js وperiod-model.mjs وresponsive.css والشعار ملفات عامة فقط.

لا توجد ملفات Excel أو بيانات الطلاب أو أسرار في هذا المستودع. تبقى النتائج في التخزين الخاص بالخدمة. رفع هذا القالب لا يفعّل ربط OneDrive السحابي؛ المزامنة الحالية من جهاز المعلم.
